# RelayRadio

RelayRadio는 **내가 고른 유튜브 플레이리스트를 집의 NAS에서 인터넷 라디오 방송국으로 바꿔 주는** 작은 서버입니다. 시놀로지 Audio Station과 iOS DS audio 앱의 라디오 기능으로 유튜브 플레이리스트를 듣고 싶어서 만들었습니다. 곡을 파일로 내려받지 않고 들을 때만 실시간으로 변환하며, 유튜브 앱의 공유 버튼 한 번으로 듣던 플레이리스트를 바꿀 수 있습니다.

> 개인 용도로 만든 프로그램입니다. yt-dlp로 유튜브에 접근하는 것은 유튜브 이용약관에 어긋날 수 있으니 혼자 또는 가족끼리 듣는 용도로만 쓰고, 스트림 주소를 공개하지 마세요.

## 기능

- **방송국(채널)**: 플레이리스트마다 `http://NAS:8000/jazz.mp3` 같은 고정 스트림 주소가 생깁니다.
- **접속할 때만 재생**: 아무도 듣지 않으면 아무 일도 하지 않습니다. 마지막 청취자가 나가고 30초 뒤 정지합니다.
- **방송 방식**: 같은 채널은 모두 같은 곡을 함께 듣습니다. 10명이 들어도 변환은 한 번만 합니다.
- **개인 스트리밍 채널**: 사용자마다 `streaming-<아이디>.mp3`가 있고, 마지막으로 공유한 플레이리스트를 재생합니다.
- **iOS 공유 단축어**: 유튜브나 YouTube Music 앱에서 공유하면 내 스트리밍 채널이 곧바로 바뀝니다.
- **이어 듣기, 셔플, 다음 곡**, 곡 제목 표시(ICY 메타데이터)를 지원합니다.
- **여러 사용자**: 웹 화면 로그인, 관리자의 사용자 관리, 방송국 공동 관리를 지원합니다.
- **비공개 플레이리스트**: `cookies.txt`를 올리면 재생됩니다.
- **yt-dlp 자동 업데이트**: 시작할 때와 하루에 한 번 업데이트하고, 웹 화면에서 바로 업데이트할 수도 있습니다.

## 실행 환경

- Docker를 쓸 수 있는 x86-64 리눅스 서버. 시놀로지 **DS923+**(DSM 7.2, Container Manager)를 대상으로 만들었습니다.
- 메모리는 전체 500MB 안팎을 씁니다. 기본 4GB면 충분합니다.
- 스트림 형식: MP3 192kbps, 44.1kHz 스테레오
- 구성 요소: Python 3.12, aiohttp, yt-dlp, ffmpeg, Deno(yt-dlp가 유튜브를 처리하는 데 필요)

## 설치 (시놀로지 Container Manager)

1. **File Station**에서 `docker/relayradio` 폴더를 만들고, 이 저장소의 파일을 모두 올립니다(`Dockerfile`, `docker-compose.yml`, `requirements.txt`, `app/` 등). 그 안에 **`data` 폴더가 있어야 합니다.** 없으면 직접 만드세요. Container Manager는 없는 폴더를 연결하지 못하고 빌드 오류를 냅니다.
2. `docker-compose.yml`의 `ADMIN_PASSWORD`를 원하는 비밀번호로 바꿉니다. 첫 실행 때만 쓰입니다.
3. **Container Manager → 프로젝트 → 생성**
   - 프로젝트 이름: `relayradio`
   - 경로: `/docker/relayradio`
   - 소스: **기존 docker-compose.yml 사용**
4. 다음을 눌러 완료하면 이미지를 빌드하고 실행합니다. 처음에는 몇 분 걸립니다.
5. 브라우저에서 `http://NAS-IP:8000`에 접속해 `admin`과 설정한 비밀번호로 로그인합니다.

데이터(사용자, 방송국, 쿠키)는 `docker/relayradio/data` 폴더에 저장됩니다.

## 사용 방법

### 방송국 만들기
웹 화면의 **새 방송국 추가**에 플레이리스트 주소, 이름, 영문 주소 이름(예: `jazz`)을 넣습니다. 다음 형식의 주소를 모두 쓸 수 있습니다.
`youtube.com/playlist?list=…`, `youtube.com/watch?v=…&list=…`, `youtu.be/…`, `music.youtube.com/playlist?list=…`

- **유튜브 믹스**(`list=RD…`)는 끝이 없는 목록이라 한 번에 100곡씩 불러옵니다. 100곡을 다 들으면 믹스를 새로 불러옵니다.
- **영상 하나만 공유하면** 그 영상으로 시작하는 유튜브 믹스를 재생합니다. 한 곡만 반복되지 않고, 라디오처럼 비슷한 곡이 이어집니다.

### DS audio에서 듣기
1. **Audio Station → 라디오 → 사용자 정의**에서 라디오 방송국을 추가합니다.
2. 이름은 자유롭게 정하고, URL에는 웹 화면의 **스트림 주소**(예: `http://192.168.0.10:8000/jazz.mp3`)를 넣습니다.
3. iOS DS audio 앱의 **라디오**에 그 방송국이 나타납니다.

### iOS 공유 단축어
웹 화면의 **iOS 공유 단축어** 칸에 나온 순서대로 단축어를 만듭니다. 화면에 내 공유 주소와 토큰이 표시됩니다. 그다음부터는 유튜브 앱에서 **공유 → (더 보기) → RelayRadio로 보내기**를 누르면 `streaming-<아이디>.mp3` 채널이 그 플레이리스트로 바뀝니다. 마음에 들면 **지금 플레이리스트를 방송국으로 저장**을 누르세요.

### 비공개 플레이리스트
브라우저 확장 프로그램 등으로 유튜브 로그인 쿠키를 `cookies.txt`(Netscape 형식)로 내보내 **관리 → 유튜브 로그인**에 올립니다. 계정 제재 위험이 있으니 주 계정 대신 **보조 계정**을 쓰는 것을 권합니다.

### 집 밖에서 듣기
NAS의 8000번 포트에 밖에서 접속할 수 있어야 합니다. VPN을 쓰거나, 시놀로지 역방향 프록시에 HTTPS를 붙이고 `PUBLIC_URL`과 `STREAM_KEY`를 설정하세요.

## 설정 (docker-compose.yml 환경 변수)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `ADMIN_USER` / `ADMIN_PASSWORD` | `admin` / (임의 생성) | 첫 실행 때 만드는 관리자 계정. 비밀번호를 비워 두면 로그에 출력됩니다 |
| `BITRATE` | `192` | MP3 비트레이트(kbps) |
| `GRACE_SEC` | `30` | 마지막 청취자가 나간 뒤 정지까지 기다리는 시간(초) |
| `AUTO_UPDATE` | `1` | 시작할 때와 하루에 한 번 yt-dlp 업데이트 |
| `PUBLIC_URL` | (자동) | 화면에 표시할 기본 주소. 예: `https://radio.example.com` |
| `STREAM_KEY` | (없음) | 설정하면 스트림 주소에 `?key=…`가 있어야 재생됩니다 |

## 문제 해결

- **곡이 재생되지 않고 "곡 재생 실패"가 표시될 때**: 관리 화면에서 **yt-dlp 지금 업데이트**를 누르세요. 유튜브가 바뀌면 yt-dlp도 업데이트되어야 합니다.
- **처음 접속하면 몇 초 동안 조용할 때**: 첫 곡을 준비하는 동안(2~7초) 무음을 보내기 때문입니다. 정상입니다.
- **로그 확인**: Container Manager → 컨테이너 → relayradio → 로그
