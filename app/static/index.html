iOS 공유 단축어

유튜브 앱의 공유 버튼으로 플레이리스트를 보내면 내 스트리밍 채널이 바로 그 플레이리스트로 바뀝니다.

  1. 단축어 앱 → + → 이름 RelayRadio로 보내기
  2. 설정(ⓘ)에서 공유 시트에서 보기를 켜고, 받을 입력을 URL과 텍스트로 지정
  3. URL의 콘텐츠 가져오기 동작 추가
    • URL:
    • 방법: POST, 요청 본문: JSON
    • url (텍스트) = 단축어 입력
    • token (텍스트) =
  4. (선택) 알림 표시 동작을 추가하고 내용에 URL의 콘텐츠를 넣기
